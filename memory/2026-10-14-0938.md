# 2026-10-14 — Evento Google Calendar vía Zapier

**Lección aprendida:** el Quick Add de Zapier (`google_calendar_quick_add_event`) solo parsea bien fechas en formato **europeo `DD/MM/YYYY`** con rango de guion `HH:MM-HH:MM`. Ejemplo que funcionó:

```
instalacion shareloop auren 15/10/2026 14:00-14:30
```

**Formatos que fallan** (Google los interpreta como HOY, no la fecha indicada):
- `15 October 2026 14:00` → hoy
- `10/15/2026 2pm` → hoy (además 1h)
- `tomorrow 2pm-2:30pm` → hoy
- ISO `2026-10-15T14:00:00/...` → hoy
- El título se contamina con restos del texto de fecha si no se usa el formato correcto.

4. "Reunion Shareloop Auren 2026-10-15T14:00:00/2026-10-15T14:30:00" (14 oct 11:31-12:31)
5. "instalacion shareloop auren to" (15 oct 14:00-15:00)
