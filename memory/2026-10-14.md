- A las 19:45 UTC ya daba `401 Invalid or Inactive Token`
- Múltiples reintentos durante el día: todas las actualizaciones dieron 401
- El token mide 40 caracteres (coincide con la cookie `4g_tok`)
- **Cambios de infraestructura realizados:**
  - Egress proxy activado (`secrets.egressProxy.enabled=true`)
  - Token vinculado al host `breathecode.herokuapp.com`
  - Cambiado de `kind=secret` a `kind=env` para evitar el proxy
  - Puerto del gateway corregido de 4000 a 18789 en `openclaw.json`
- **Sospecha:** el token de cookie `4g_tok` podría no ser el token de API, o 4Geeks rota tokens muy rápido (<30 min)
